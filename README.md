# 📊 Dubai Business Dashboard

## 🎯 What is this?
My first data analytics project as a Business Computing & Data Analytics student at Middlesex University Dubai.

## 🚀 Features
1) 📈 Interactive revenue trend charts
2) 👥 Customer analytics
3) ⭐ Satisfaction ratings
4) 📊 Key metrics at a glance
